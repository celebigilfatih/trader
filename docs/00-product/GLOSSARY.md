# Glossary

| Term | Definition | Notes |
|---|---|---|
| BIST | Borsa İstanbul | Sembol listesi `modules/config.py` içinde tutulur. |
| OHLCV | Açılış, en yüksek, en düşük, kapanış ve hacim verisi | Analiz katmanının temel veri sözleşmesi. |
| İndikatör | Fiyat/hacim serisinden türetilen teknik ölçüm | RSI, MACD, EMA, VWAP vb. |
| Sinyal | Birden çok kuralın AL/SAT/BEKLE biçimindeki birleşik çıktısı | Yatırım tavsiyesi değildir. |
| Screener | Çok sayıda sembolü aynı teknik koşulla tarayan bileşen | Dış veri erişimine bağlıdır. |
| Sentiment | Haber metninden hesaplanan pozitif/nötr/negatif skor | Bazı fonksiyonlar mock veri üretir; açıkça etiketlenmelidir. |
| CDSK | Celebigil Development Standard Kit | Repository tabanlı proje işletim standardı. |
