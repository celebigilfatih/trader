# Session Handoff

Bu belge handoff formatını tanımlar; güncel kayıt `PROJECT_BOOT.md` içinde tutulur.

- **Session summary:** Bir veya iki cümle
- **Documents updated:** Dosya listesi
- **Decisions recorded:** ADR veya kaynak bağlantıları
- **Remaining risk:** Devamı etkileyen açık risk
- **Recommended next step:** Tek uygulanabilir adım
