# Definition of Done

- [ ] Kabul kriterleri karşılandı.
- [ ] Uygun lint/typecheck/test/build kontrolleri geçti.
- [ ] Güvenlik, gizlilik ve veri etkileri değerlendirildi.
- [ ] Geriye uyumluluk ve rollback değerlendirildi.
- [ ] İlgili belgeler güncellendi.
- [ ] ADR ve changelog gereksinimi tamamlandı.
- [ ] Project Boot ve AI Handoff güncellendi.
- [ ] Açık riskler raporlandı.

## Project-specific evidence

- [ ] Finansal veri kaynağı, veri zamanı ve mock/tahmin niteliği doğrulandı.
- [ ] Dış entegrasyon başarı, timeout ve hata yolu test edildi veya gerekçeli N/A.
- [ ] Üretilen JSON/CSV/PDF/model artifact'larının sahiplik ve retention etkisi
  değerlendirildi.
- [ ] Yatırım tavsiyesi olmadığına dair kullanıcı iletişimi korundu.
